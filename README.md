**Data Analysis Files Overview**

This repository contains the SQL, Python, and Power BI files used to analyze and visualize Sarda En’s financial and operational data. Together, these components form an end-to-end analytical workflow that transforms raw datasets into actionable business insights. Each file plays a distinct role in data extraction, processing, analysis, and visualization.

SQL Files

The SQL files are responsible for extracting, filtering, and structuring the raw financial data used throughout the analysis process. These scripts are used to query datasets and prepare key business information

SQL queries help clean and organize data into structured formats suitable for further processing and reporting. They also support aggregations, calculations, and transformations required for meaningful analysis.

Python Files

The Python scripts are used for data preprocessing, analysis, and additional transformation tasks prior to visualization.
Python enables automation and analytical flexibility, making it easier to process complex datasets and uncover patterns that support business decision-making.

Power BI Files

The Power BI dashboard serves as the final analytical layer, converting processed data into an interactive and visually engaging experience. It provides a comprehensive view of Sarda En’s financial and operational performance by presenting key indicators through intuitive visualizations.

The dashboard includes insights related to:

Sales performance trends
Net profit analysis
Operating performance metrics
Earnings Per Share (EPS)
Profit Before Tax (PBT)
Overall financial health indicators

Power BI's interactive capabilities, including filters, slicers, and drill-down functionality, allow users to explore data dynamically, compare different time periods, and identify trends or anomalies efficiently.

The dashboard is designed with clarity and usability in mind, using KPIs, charts, and graphical elements to simplify financial analysis. This enables both technical and non-technical stakeholders to gain insights and make informed, data-driven decisions.
